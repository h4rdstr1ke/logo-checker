# LogoScope (Проверка логотипов и фавиконов)

Веб-приложение на **Next.js (App Router)** с полным набором тестов (**Vitest + Testing Library**) для визуальной проверки отображения логотипа и фавикона:
1. **Во вкладках браузеров**:
   - Google Chrome (Desktop): активная вкладка, неактивная вкладка, закрепленная вкладка (pinned tab), панель закладок.
   - Apple Safari (macOS): компактная строка с замком безопасности и доменом.
   - Поддержка темного (Dark) и светлого (Light) режимов.
2. **В поисковой выдаче (SERP)**:
   - Google (Десктоп и Мобильный): круглый значок 28×28 с иконкой 18×18, название сайта, хлебные крошки/URL, сниппет и быстрые ссылки.
   - Яндекс (Десктоп и Мобильный): фавикон 16×16 рядом с адресом, сниппет, галочка официального сайта и рейтинг.
3. **Диагностика контраста и читаемости**:
   - Проверка контрастности по WCAG относительно темных и светлых фонов браузера (предупреждение, если темный логотип на прозрачном фоне сольется с темной темой вкладки).
   - Инспектор пиксельной сетки (16×16, 32×32, 48×48 и 6× Zoom).
4. **Генерация и экспорт**:
   - Скачивание фавиконов всех стандартных размеров (`16x16`, `32x32`, `48x48`, `180x180` Apple Touch, `192x192` и `512x512` Android/PWA), сгенерированных прямо в браузере через HTML5 Canvas.
   - Готовый HTML-код для тега `<head>` и манифест `site.webmanifest`.

## 🚀 Быстрый старт

### Запуск сервера разработки
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### Запуск тестов
```bash
# Однократный запуск всех тестов
npm test

# Режим наблюдения (watch mode)
npm run test:watch
```

### Сборка для продакшена
```bash
npm run build
npm start
```

### Линтинг
```bash
npm run lint
```
