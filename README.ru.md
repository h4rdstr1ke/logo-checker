# 👁️ LogoScope

**Интерактивный инструмент проверки и тестирования логотипов и фавиконов во вкладках браузеров и результатах поисковой выдачи.**

Больше никаких размытых фавиконов и черных логотипов, исчезающих на темной теме Chrome.

## 💡 Проблема, с которой сталкивается каждый разработчик

Создавая веб-приложение или сайт, разработчики тратят часы на интерфейс, верстку и логотип. Но после деплоя регулярно всплывают неприятные сюрпризы:

- **Ловушка темной темы**: Темный логотип на прозрачном фоне отлично смотрится на белом холсте в макете, но на темной теме Chrome или Arc (`#202124`) полностью растворяется, превращаясь в пустое место.
- **Обрезка в Google SERP**: Поисковик оборачивает фавикон в круглую плашку 28×28 px (с областью иконки 18×18 px). Квадратные значки обрезаются по углам, а мелкие надписи становятся нечитаемыми.
- **Потеря четкости в 16×16 px**: Логотип, великолепно выглядящий в разрешении 512×512, в браузерной вкладке превращается в бесформенное размытое пятно.
- **Рутина подготовки форматов**: Ручная нарезка фавиконов под `16x16`, `32x32`, `apple-touch-icon 180x180`, генерация `site.webmanifest` и прописывание тегов `<link>`.

**LogoScope** решает эти проблемы, предоставляя разработчикам мгновенную интерактивную песочницу для тестирования, адаптации и выгрузки готовых ассетов до релиза.

## ✨ Возможности

### 1. 🗂️ Вкладки браузеров в реальном масштабе
- **Google Chrome (Desktop)**:
  - **Активная вкладка**: Точная геометрия вкладки, обрезка длинных заголовков, кнопка закрытия и индикатор звука.
  - **Неактивная вкладка**: Наглядная проверка того, насколько ваш логотип выделяется на фоне соседних вкладок.
  - **Закрепленная вкладка (Pinned Tab 16×16)**: Компактный режим с одной лишь иконкой.
  - **Панель закладок (Bookmarks bar)**: Отображение сайта в строке избранного.
  - **Светлая и темная темы**: Мгновенный переключатель между `#dfe1e5` и `#202124`.
- **Apple Safari (macOS)**:
  - Компактная объединенная строка с замочком безопасности, доменом и фавиконом.
  - Светлый и темный режимы оформления macOS.

### 2. 🔍 Поисковая выдача (SERP)
- **Google (Десктоп и Мобильный)**:
  - Аутентичный круглый бейдж 28×28 px (иконка 18×18 px).
  - Форматирование хлебных крошек (`https://domain.com › category › page`).
  - Синий кликабельный заголовок (`#1a0dab` в светлой теме / `#8ab4f8` в темной).
  - Двухстрочный сниппет и блок быстрых ссылок (sitelinks).
- **Яндекс (Десктоп и Мобильный)**:
  - Фирменное расположение фавикона 16×16 px слева от зеленовато-серого URL.
  - Галочка «Официальный сайт», сниппет, звездочки рейтинга и быстрые ссылки.

### 3. 🎨 Настройка формы, подложки и отступов
- **Формы подложки**: Без подложки (оригинал с прозрачностью), Круг, Squircle (скругленный квадрат) или Квадрат.
- **Цвет плашки**: Быстрые цвета (белый, черный, серый под тему Chrome) или точный выбор любого цвета через Hex-палитру.
- **Ползунок внутреннего отступа (Padding 0% - 35%)**: Дает логотипу «воздух», чтобы он не упирался в края фавикона.
- **Drag & Drop и вставка из буфера (Ctrl+V)**: Просто перетащите `.svg`, `.png`, `.jpg`, `.webp`, `.ico` или скопируйте картинку в буфер и нажмите **`Ctrl+V`**.

### 4. 🩺 Диагностика контрастности и видимости (WCAG)
- Автоматический расчет относительной яркости и коэффициента контрастности.
- Оценка видимости (`Отлично`, `Внимание`, `Сливается`) для 4 стандартных сценариев:
  - Светлая вкладка Chrome (`#dee1e6`)
  - Темная вкладка Chrome (`#292a2d`)
  - Светлый фон Google / Яндекс (`#ffffff`)
  - Темная тема Google SERP (`#202124`)
- Инспектор пиксельной сетки: 100% масштаб (**16×16 px**), 200% (**32×32**), 400% (**48×48**) и **6× увеличение**.

### 5. 📦 Клиентский экспорт и генератор кода
- **100% Client-Side**: Никаких загрузок на внешние серверы, конфиденциальность данных, быстрая работа без сети.
- **Скачивание полного комплекта фавиконов**:
  - `favicon-16x16.png` (Базовая вкладка)
  - `favicon-32x32.png` (Retina / экраны высокой плотности)
  - `favicon-48x48.png` (Закладки и ярлыки рабочего стола)
  - `apple-touch-icon.png` (180×180 для домашнего экрана iOS)
  - `android-chrome-192x192.png` (Android / PWA)
  - `android-chrome-512x512.png` (Splash-экран PWA)
- **Готовый код**: Теги `<link>` для `<head>` и файл конфигурации `site.webmanifest` для PWA.

## 🚀 Быстрый старт

### Требования
- Node.js `20.x` или `22.x`
- npm `9+`

### Установка и запуск

```bash
# Клонируйте репозиторий
git clone https://github.com/h4rdstr1ke/logo-checker.git
cd logo-checker

# Установите зависимости
npm install

# Запустите сервер разработки
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 🧪 Тестирование

Проект покрыт автоматическими тестами на **Vitest** и **React Testing Library** (31 тест для утилит, компонентов и страниц):

```bash
# Однократный запуск всех тестов
npm test

# Запуск тестов в режиме наблюдения (watch)
npm run test:watch

# Запуск линтера
npm run lint

# Сборка для продакшена
npm run build
```
